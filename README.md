# Calculator App

Modern calculator built with React + TypeScript.

## 🚀 Features
- Basic operations (+, -, *, /)
- Clean UI
- Component-based structure
- Fast with Vite

## 🛠 Tech Stack
- React
- TypeScript
- Vite

## 📂 Project Structure
src/
 ├── components/
 │    └── Calculator
 ├── App.tsx
 └── main.tsx

## ⚙️ Run Locally
npm install
npm run dev

## 🎯 Purpose
This project demonstrates component architecture and state management in React.
